# Woody Booth

A website for Woody Booth — a vintage-trailer-turned-mobile-photo-booth business — built to showcase the business, list what's included with a booking, and let potential customers get in touch.

## About This Project

This is a client-style project I built to practice creating a small business website from scratch: a hero section, service highlights, and a working contact form, all styled with a custom vintage/western theme.

## Built With

- HTML5
- CSS3 (custom styling on top of Bootstrap)
- [Bootstrap 5](https://getbootstrap.com/)
- Google Fonts (Bricolage Grotesque, Playwrite GB S, Rye)
- [Netlify Forms](https://docs.netlify.com/forms/setup/) for contact form handling (no backend needed)

## Features

- Responsive navbar with smooth-scroll links to each section
- Full-screen hero section with a call-to-action button
- "About" section introducing the business
- Service/rate highlights (props, prints, scheduling)
- Working contact form with spam protection (honeypot field), powered by Netlify Forms
- Mobile-friendly layout with adjusted hero sizing on smaller screens

## Running It Locally

This is a static site, so there's no build step:

1. Clone the repo
   ```bash
   git clone https://github.com/Ivan-glitch90/woody-booth.git
   ```
2. Open `index.html` in your browser (or use the VS Code "Live Server" extension for auto-reload)

> **Note:** The contact form only works once this is actually deployed on Netlify — that's what makes `data-netlify="true"` function. Locally, submitting the form won't do anything yet.
